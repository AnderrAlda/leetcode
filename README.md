# LeetCode

Mis soluciones a problemas de LeetCode, en Python.

## Uso

```bash
source .venv/bin/activate   # una vez por sesión de terminal
./new.sh 15 3sum            # crea problems/0015-3sum/
pytest                      # corre todos los tests
pytest problems/0001-two-sum # corre solo uno
```
